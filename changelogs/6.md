### 🎬 Nova v1.1.0 — Wallpaper Engine Persistence, Automation Tools & Super Wallpapers

- **Prevent Static Reversion on Update & Launch**: Eliminated destructive `WallpaperManager.setBitmap()` calls in `WallpaperColorHelper` that previously displaced and unbound the active `LiveWallpaperService` with a static bitmap whenever wallpapers were previewed or applied.
- **Non-Destructive Samsung One UI & Material You Palette Sync**: Preserved authentic dynamic Color Palette generation exclusively via `LiveWallpaperService.onComputeColors()` and `notifyColorsChanged()`, providing system-wide accent theming without overriding the live wallpaper engine.
- **Eliminated Visibility & Surface Lifecycle Race Condition**: Fixed race condition where `onVisibilityChanged(true)` flagged `hasPlayedThisSession = true` before `onSurfaceCreated()` finished attaching a valid surface, preventing playback from becoming permanently frozen at 0 ms.
- **Android 14 / One UI 6 System Broadcast Compliance**: Switched `screenReceiver` registration to `Context.RECEIVER_NOT_EXPORTED` for system-protected events (`ACTION_SCREEN_ON`, `ACTION_SCREEN_OFF`, `ACTION_USER_PRESENT`), ensuring screen-off lock events reliably reset the playback session.
- **ExoPlayer Decoder & State Auto-Recovery**: Introduced `onPlayerError` listener and default wallpaper fallback to seamlessly re-prepare media and rebind video surfaces if package updates invalidate open asset streams.
- **Automated Batch Wallpaper Compression Tool**: Included `compress_wallpapers.sh` script providing automated H.265 (`libx265`) batch video compression, 10-bit color preservation, and audio stripping with ~96.5% file size reduction.
- **Interactive Wallpaper Import & Removal CLI Tools**: Added `add_wallpaper.sh` and `remove_wallpaper.sh` for batch importing local video folders, generating seamless reverse animations (`_rev.mp4`), extracting resting & start thumbnails, creating system wallpaper picker services, and cleanly managing collection entries.
- **New Super Wallpaper Collections**:
  - **Pixel 11 Fold**: Added *Midnight*, *Midnight Dark*, *Pine*, and *Pine Dark* with full 0ms AOD reverse animation tracks, resting thumbnails, and dynamic Samsung One UI palettes.
  - **Pixel 10 Fold**: Added *Green*, *Green Dark*, *Silver*, and *Silver Dark* fluid blob super wallpapers with complete dual-player reverse support.
- **Ultra-Slim APK Size via On-Demand Wallpaper Downloading**: Reduced release APK footprint from ~50 MB to 15 MB. All cover thumbnails (~2.8 MB) and the default *ColorOS 17 Flow* live wallpaper remain bundled in the app for instantaneous offline preview and usage. Additional wallpapers are downloaded on-demand with real-time progress indicators and saved permanently to app storage (`context.filesDir/wallpapers/`) for future offline use.
